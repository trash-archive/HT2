# HT² — Couples Connection App

A personal Android app built for couples to deepen their 
connection through meaningful conversations.

## Features
- 1,000+ swipeable question cards across 20+ categories
- Like, Dislike & History tracking
- Custom question prompts
- Couple Profile Card
- Secret Journal
- Hidden easter egg 🌸

## Tech Stack
Kotlin · Jetpack Compose · MVVM · StateFlow · DataStore · Material 3 · Coil
